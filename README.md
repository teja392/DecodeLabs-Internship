# LuxeSpace Studio

A modern and elegant interior design studio website created as part of the **Week 1 Web Development Project**.

LuxeSpace Studio is designed to showcase architecture, interior design, exterior design, landscape planning, commercial spaces, and luxury living concepts through a clean and visually appealing website.

---

## 🌟 Project Overview

LuxeSpace Studio is a fictional interior and architecture design studio that focuses on creating beautiful, functional, and sophisticated spaces.

The website presents the studio's services, design projects, team, gallery, testimonials, frequently asked questions, and contact information in a professional multi-page layout.

The main focus of this project was to build the website structure and visual design using **HTML5 and CSS3**.

##  How to Run the Project

### Option 1 — Open Directly

Open the `index.html` file in any modern web browser.

### Option 2 — Using VS Code Live Server

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The website will then open in your browser.
